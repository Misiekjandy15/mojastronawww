📊 Baza Danych Użytkowników - Kompleksowy System

Kompletny system rejestracji i logowania z bazą danych SQLite

🎯 Przegląd Projektu

Kompletny system rejestracji i logowania z bazą danych SQLite. Projekt zawiera:

  • ✅ Backend Flask z REST API
  • ✅ Frontend HTML/CSS/JavaScript
  • ✅ Baza danych SQLite
  • ✅ Zarządzanie użytkownikami
  • ✅ Haszowanie hasła SHA256
  • ✅ Testy API
  • ✅ Pełna dokumentacja

🚀 Szybki Start (5 minut)

  1. Zainstaluj pakiety
    pip install -r requirements.txt
  2. Uruchom serwer
    python app.py
  3. Otwórz w przeglądarce
    baza_danych_index.html
  4. Zarejestruj się i zaloguj!

📋 Tabela Bazy Danych

CREATE TABLE users ( id INTEGER PRIMARY KEY AUTOINCREMENT, username TEXT UNIQUE NOT NULL, password TEXT NOT NULL (SHA256), created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );

Kolumny:

  • id - Unikalny identyfikator
  • username - Nazwa użytkownika (unikalna)
  • password - Hasło haszowane SHA256
  • created_at - Data rejestracji

🌐 API Endpoints

Metoda Endpoint Opis
POST /api/register Rejestracja nowego użytkownika
POST /api/login Logowanie użytkownika
POST /api/logout Wylogowanie
GET /api/check-login Sprawdzenie statusu

🛠️ Zarządzanie Bazą Danych

Wyświetl użytkowników

python manage_db.py list

Dodaj użytkownika

python manage_db.py add username password

Usuń użytkownika

python manage_db.py delete username

Policz użytkowników

python manage_db.py count

Resetuj bazę

⚠️ usuwa wszystko!
python manage_db.py reset

❓ Problemy?

"Błąd podczas logowania"

  • Sprawdź czy serwer jest uruchomiony (python app.py)
  • Sprawdź czy port 5000 jest dostępny
  • Przeczytaj INSTRUKCJA.md sekcję Troubleshooting

"Port 5000 jest zajęty"

netstat -ano | findstr :5000 taskkill /PID <PID> /F

"ModuleNotFoundError"

pip install -r requirements.txt

Więcej pomocy

  • Przeczytaj README_BAZA_DANYCH.md
