app.py (Flask Backend)

        ↓ (SQL Query)

users.db (SQLite Database)
    │
    └─ TABLE: users
        ├─ id (INTEGER, PRIMARY KEY, AUTO INCREMENT)
        ├─ username (TEXT, UNIQUE, NOT NULL)
        ├─ password (TEXT, NOT NULL, SHA256)
        └─ created_at (TIMESTAMP)

═══════════════════════════════════════════════════════════════════════════
                    🔐 PRZEPŁYW DANYCH
═══════════════════════════════════════════════════════════════════════════

REJESTRACJA:
    1. Użytkownik wpisuje dane w przyciskrejstracji.html
    2. JavaScript wysyła POST do /api/register
    3. Backend waliduje dane
    4. Backend hashuje hasło (SHA256)
    5. Backend sprawdza czy username jest unikalny
    6. Backend INSERT INTO users
    7. Odpowiedź: "Konto założone"
    8. Redirect do loginpanel.html

LOGOWANIE:
    1. Użytkownik wpisuje dane w loginpanel.html
    2. JavaScript wysyła POST do /api/login
    3. Backend szuka użytkownika
    4. Backend hashuje podane hasło
    5. Backend porównuje hashe
    6. Jeśli zgadza się: tworzy sesję
    7. Redirect do index.html
    8. Session przechowuje: user_id, username

                    📊 STRUKTURA BAZY DANYCH
═══════════════════════════════════════════════════════════════════════════

users.db (SQLite)
│
└─ TABLE: users
    │
    ├─ COLUMNS:
    │   ├─ id: Unikalny identyfikator (1, 2, 3, ...)
    │   ├─ username: Nazwa użytkownika (michal, anna, tomasz)
    │   ├─ password: SHA256 hash hasła (78a1c71d7...8c42...)
    │   └─ created_at: Data i czas (2026-01-26 10:30:00)
    │
    ├─ INDEXES:
    │   └─ idx_username (szybkie wyszukiwanie po username)
    │
    └─ CONSTRAINTS:
        ├─ PRIMARY KEY (id)
        ├─ UNIQUE (username)
        └─ NOT NULL (username, password)

═══════════════════════════════════════════════════════════════════════════
                    🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEM: "Nie mogę się zalogować"
  └─ ROZWIĄZANIE:
     1. Sprawdź czy serwer jest uruchomiony (terminal powinien pokazać port 5000)
     2. Sprawdź czy hasło jest poprawne (case-sensitive!)
     3. Przeczytaj console.log w przeglądarce (F12)

PROBLEM: "Port 5000 jest już w użyciu"
  └─ ROZWIĄZANIE: netstat -ano | findstr :5000
                  taskkill /PID <PID> /F

PROBLEM: "ModuleNotFoundError: No module named 'flask'"
  └─ ROZWIĄZANIE: pip install -r requirements.txt

PROBLEM: "CORS error"
  └─ ROZWIĄZANIE:
     1. Upewnij się że Flask-CORS jest zainstalowany
     2. Sprawdź czy serwer na porcie 5000 jest włączony
     3. Otwórz F12 i sprawdź Network tab

PROBLEM: "Baza danych nie istnieje"
  └─ ROZWIĄZANIE:
     1. Baza jest tworzona automatycznie
     2. Jeśli brakuje: usuń users.db
     3. Uruchom python app.py
