📱 Jak zacząć?

Krok 1: Instalacja

Zainstaluj wymagane pakiety Python:

pip install -r requirements.txt

Krok 2: Uruchomienie serwera

Uruchom backend Flask:

python app.py

Serwer będzie dostępny na: http://localhost:5000

Krok 3: Logowanie/Rejestracja

Otwórz plik loginpanel.html w przeglądarce i zarejestruj się lub zaloguj.

Krok 4: Zarządzanie

Użyj panelu administracyjnego lub komendy CLI:

python manage_db.py list

🔧 Dostępne Narzędzia

🖥️ Interfejsy Graficzne

  • loginpanel.html - Panel logowania
  • przyciskrejstracji.html - Panel rejestracji
  • panel_bazy_danych.html - Panel zarządzania bazą

⌨️ Narzędzia CLI

  • python manage_db.py list - Wyświetl użytkowników
  • python manage_db.py add <user> <pass> - Dodaj użytkownika
  • python manage_db.py delete <user> - Usuń użytkownika
  • python manage_db.py count - Policz użytkowników
  • python test_api.py - Testuj API

🔗 API Endpoints

  • POST /api/register - Rejestracja
  • POST /api/login - Logowanie
  • POST /api/logout - Wylogowanie
  • GET /api/check-login - Sprawdzenie statusu

📦 Struktura Projektu

  • app.py - Backend Flask API
  • *.html - Interfejsy użytkownika
  • manage_db.py - Zarządzanie bazą CLI
  • test_api.py - Testy API
  • users.db - Baza danych SQLite (auto-created)
  • requirements.txt - Wymagane pakiety

🔒 Bezpieczeństwo

  • ✅ Hasła haszowane (SHA256)
  • ✅ Nazwy unikalne
  • ✅ Walidacja na backendu
  • ✅ CORS security
  • ✅ Session management
